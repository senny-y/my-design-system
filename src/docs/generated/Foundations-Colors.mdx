# Colors

Figma 이름, 코드 이름(CSS 변수), Code syntax를 한 줄에 보여줍니다. 견본의 색은 실제 토큰 CSS에서 가져옵니다.

## primitive

원본 색상 값입니다. 컴포넌트에서는 직접 쓰지 않고 semantic을 통해서만 씁니다.
